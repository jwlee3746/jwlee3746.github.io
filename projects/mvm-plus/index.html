MVM+ · 생성 모델에 metric 심기

고객이 맡긴 학습용 데이터를 진단하고 개선하는 '데이터 클리닉' 과제입니다. 가상 데이터를 사람이 한 장씩 만드는 방식은 고비용·저효율이라, 생성 모델로 대체하되 "생성된 데이터가 원본과 얼마나 닮았는지"를 잴 수 있어야 했습니다. 그 자를 만드는 일이 제 몫이었습니다.

배경

Pebblous는 가상 데이터를 다루는 회사입니다. 여기서 '데이터 클리닉' — 차세대 AI 학습용 데이터를 진단하고 개선하는 연구 개발 —에 참여했습니다.

출발점은 명확했습니다. 고화질 가상 데이터를 하나씩 직접 만들어 학습에 쓰는 것은 비용 대비 효율이 너무 나빴습니다. 그래서 세 가지를 하려고 했습니다.

1. 고품질 가상 데이터를 직접 만들기에는 비용이 크다 → 생성 모델을 쓰자
2. 고객 데이터를 받아 “의미 있는” 매니폴드를 만들자
3. 진단 결과를 고객에게 시각화해서 보여주자

여기서 자연스럽게 질문이 따라 나옵니다. 의미 있는 매니폴드를 만들려면 어떤 데이터가 서로 유사한지를 알아야 하고, 그러려면 metric이 필요합니다. 시각화 역시 t-SNE, UMAP, TensorBoard projector 같은 도구로 2·3차원에 내려놓을 수 있어야 합니다. AI 학습에는 질적 개선보다 양적 증강이 더 효과적일 수 있다는 판단도 생성 모델 쪽에 힘을 실었습니다.

맨땅에서 모델 고르기

후보를 넓게 놓고 봤습니다. VAE 계열, GAN 계열, StyleGAN이나 VVAE 같은 고해상도 생성 모델, 그리고 diffusion 계열까지.

결론은 한 문장으로 정리됐습니다. 생성은 다들 잘하는데, 어디가 부족하고 어떤 데이터가 서로 유사한지를 말해 주는 metric이 없다.

그러다 metric learning과 생성 모델을 붙인 논문을 찾았습니다 — Manifold Matching via Deep Metric Learning for Generative Modeling (MVM). 여기서 출발하기로 했습니다.

부딪힌 문제

차원의 저주

차원이 커질수록 데이터는 공간의 가장자리로 밀려나고 서로 지수적으로 멀어집니다. 모든 거리가 사실상 무한대로 수렴하면 metric은 의미를 잃습니다. 이미지 생성 모델은 layer가 깊고 차원이 높아 이 문제가 특히 심합니다.

MVM 자체의 설계 문제

기반으로 삼은 MVM에도 손볼 곳이 있었습니다.

  • Manifold matching loss — 두 임베딩 다양체의 중심과 크기만 맞추는 naive한 방식이었습니다. 형상은 보지 않습니다.
  • Triplet loss — 각도 기반 metric과 거리 기반 metric을 섞어 쓰는 구조라, 두 척도가 서로를 방해했습니다.

MVM+

Average Hausdorff loss 고안

중심과 크기만 맞추던 자리를 Hausdorff distance로 바꿨습니다. 임베딩을 이루는 데이터 포인트를 1대다로 매칭해, 생성된 다양체가 진짜 데이터의 형상 자체를 반영하고 그대로 따라가도록 설계했습니다.

Triplet loss → Cosine Similarity loss

Triplet loss에서 제대로 작동하지 않던 유클리디언 거리 부분을 걷어냈습니다. 생성된 가짜 데이터를 매니폴드 가운데 두고 밀어내는 형상은 유지하면서, 각도와 거리를 섞어 쓰던 문제를 없앴습니다.

얻은 것은 두 가지입니다. 진짜 데이터와 생성 데이터 사이의 적대적 관계가 유지되고, 남은 각도 metric으로 유사도 평가와 시각화가 가능해졌습니다.

실험

세 단계로 검증했습니다.

  • 2차원 가상 데이터 — 다양한 형태의 2D 매니폴드를 생성할 수 있는지 확인. MVM과 MVM+를 epoch 1과 epoch 100 시점에서 비교했습니다.
  • MNIST — MVM+와 일반 GAN을 나란히 비교.
  • celebA — 고해상도 이미지에서의 동작 확인.

스스로 매긴 점수

연구를 시작할 때 세웠던 세 가지 목표를 다시 꺼내 하나씩 따져 봤습니다.

1. 고품질 가상 데이터 생성 — 충족

GAN 기반 생성 모델인 MVM으로 학습 데이터와 유사한 가상 데이터를 만들 수 있었습니다.

2. 의미 있는 매니폴드 — 미흡

데이터 간 유사성을 고려하는 metric learning 방식의 생성 자체는 가능했습니다. 실제로 MNIST 결과를 보면 같은 레이블의 데이터끼리 모이는 모습이 확인됩니다. 다만 고객 데이터에서 "필요한 부분에 집중한다"는 원래 목표에는 못 미쳤습니다.

3. 진단 결과 시각화 — 한계가 남음

각도 metric으로 유사도를 재고 시각화할 길은 열렸지만, 근본적인 제약이 남았습니다. MVM+는 어디까지나 GAN을 변형한 생성 모델이고, metric보다 생성 쪽에 무게를 두고 설계되어 있습니다. 진단 도구로 쓰려면 데이터 사이의 metric 혹은 contrastive한 관계를 더 강화해야 한다는 것이 남은 결론이었습니다.

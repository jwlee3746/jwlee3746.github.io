Bixby LLM·에이전트 평가 서비스

2024.07 — 현재

Evaluation Architecture · JSON Schema · CI

평가 자산을 계약–검증–실행–채점–리포트로 계층화해 모델 판단을 반복 비교할 수 있는 워크플로 구축

  • 평가 계약 — 한국어 에이전트 TC를 canonical format으로 표준화하고 context·tool output·근거 provenance를 함께 보존
  • 검증 경계 — JSON Schema 기반 계약을 정의하고 merge 전 CI gate와 실행 전 preflight가 같은 validator를 공유하도록 설계
  • Multi-step replay — request projection과 expected path를 분리해 정답 누출을 막고, alternative path를 독립된 history로 실행
  • 경로 채점 — structured action과 복수 정답 path, capability continuation을 구분하는 deterministic scoring 구현
  • 실행 복구 — checkpoint/resume·동시성·간격 예산과 데이터·schema·모델·runtime·채점 revision을 결과 artifact에 기록
